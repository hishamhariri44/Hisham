# Hisham Hariri — Film, Colour & Perspective

Complete static portfolio. The opening film has separate desktop and phone edits; AI energy-drink and candy collections have their own reels. Full project videos retain their audio. The four montage exports are silent website edits.

## Preview

Open index.html in a browser, or serve this folder using any static web server. Internet is required for YouTube films and Google Fonts; local films and the system-font fallback work independently.

## GitHub Pages

Extract the ZIP first. Upload the extracted website files, not the ZIP itself. For a large media folder, use GitHub Desktop to commit the complete folder, or use the numbered browser-upload folders in the separate GitHub Upload Kit. Upload one numbered folder's CONTENTS at a time at the repository root, keeping media/, posters/ and assets/ as folders. Commit each batch before starting the next. Never upload the numbered wrapper folders themselves.

Every included file is below GitHub's 25 MiB browser file limit. The upload kit also keeps each batch below 24 MiB and 100 files. Choose main and / (root) in Settings → Pages if using branch publishing. All paths are relative, so the site works under /Hisham/. No install or build command is needed. The media folder must exist for background loops and locally hosted films to play.

## Edit

- index.html: page structure, introduction, biography and contact.
- portfolio.css: layout, colours and responsive styles.
- portfolio-data.js: projects, descriptions and film versions.
- portfolio.js: filters, video viewers, photo viewer and playback controls.
- media/: optimized website videos.
- posters/ and assets/: video covers, photographs and original logo copies.
